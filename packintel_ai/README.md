## Features

- **🤖 AI-Powered Recommendations**: Hybrid RAG (Retrieval-Augmented Generation) pipeline combining vector search and keyword retrieval
- **📦 10 Packaging Materials**: PET, HDPE, LDPE, PP, Glass, Aluminum, Paperboard, PLA, PHA, Multilayer
- **🎯 Transparent Scoring**: 6-dimensional compatibility scoring with explainable AI
- **🔄 What-If Simulator**: Change conditions in real-time and see how recommendations shift
- **📊 Material Comparison**: Side-by-side comparison with radar charts and property matrices
- **📚 Knowledge Base**: Upload and index custom PDF, TXT, CSV, JSON documents
- **🌙 Demo Mode**: Fully functional offline mode without external API dependencies
- **🎨 Beautiful UI**: Dark theme, glassmorphism, neon accents, smooth animations
