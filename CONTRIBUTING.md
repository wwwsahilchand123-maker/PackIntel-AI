# Contributing to PackIntel-AI

PackIntel-AI focuses on packet and network intelligence for authorized analysis and research.

## Guidelines

- Keep parsing and analysis changes testable and focused.
- Never commit real captures containing credentials or personal information.
- Document new fields, detection heuristics, and expected input formats.
- Run the project's available tests before submitting a pull request.

## Pull requests

Explain what changed, how it was tested, and any performance, privacy, or security implications. Use sanitized sample data for examples.
